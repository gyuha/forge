- 계획대로 된 것: 3슬라이스(S1 fg-eco SKILL.md / S2 fg-run 캡 enactment / S3 12스킬·3키 문서 동기화) 전부 완료 — 합의대로 Dynamic Workflow 없이 본 세션 직접 처리, 완료 기준 전부 정적 검증(awk/grep/node/ls)으로 통과.

## Learnings
- 다음에 다르게 할 것:
  - **불확실한 플랫폼 능력이 걸린 요청은 "가능성 검토"를 그릴링 첫 질문으로** — 이번에 첫 질문에서 "스킬은 세션 모델을 못 바꾼다"가 확정되며 불가능한 절반을 실행 전에 잘라냈다. 또한 **요청된 이름이 구현 불가한 약속을 담고 있으면 개명이 옳다**(auto-model은 세션 전환을 암시 → eco로 정직하게).
  - **"스킬 1개 추가"의 ripple 표면은 CONCERNS #2 예측 그대로였다** — 매니페스트 description 2벌, README 양쪽의 카운트·표·트리거 문단(각 3곳), CLAUDE.md 목록, config 키 서술 2곳(fg-tdd·FORGE-ROOT). `.forge/codebase/CONCERNS.md`가 실전 체크리스트로 작동했다 — 스킬 추가 작업은 앞으로도 이 항목을 슬라이스 체크리스트로 쓸 것.
- 후속 작업 후보 (fg-quick 감):
  - `CLAUDE.md` 루프 밖 스킬 목록에 **fg-tdd가 선재 누락**(이번에 fg-eco는 추가, fg-tdd는 surgical 원칙으로 미수정 — 한 단어 거리).
  - `plugin.json`의 fg-tdd 절이 구식 어구("fg-ask then defaults to asking") — README·fg-tdd 본문은 2차 감사에서 "asks per task"로 정정됐으나 매니페스트는 미정정.
