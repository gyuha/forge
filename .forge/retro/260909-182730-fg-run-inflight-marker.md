## 학습
- 다음에 다르게:
  - **새 상태 파일의 소비자는 grep으로 도출한다** — "누가 이 파일을 읽어야 하나"를 머리로 열거하면 봉인·주행·STEP 0처럼 *파일을 비우거나 우회하는* 쪽이 빠진다. `grep -l 'plan.md\|run.md' skills/*/SKILL.md scripts/*.sh`로 활성 슬롯을 만지는 전 표면을 뽑아 각 표면에 "이 마커가 있으면?"을 묻는 것이 그릴링의 한 단계여야 한다(#146 S1–S5가 그 누락을 메우는 비용).
  - **DoD의 개수 단정은 계수 방식·기대값 도출 근거를 함께 적는다** — "= N"을 쓰기 전에 같은 부류의 선례(A9)에 그 정규식을 한 번 돌려 본다. 트윈은 인용 방식이 달라 같은 grep이 다른 수를 낸다.
  - **기준선은 옮겨 적지 않고 잰다** — 앞 run.md의 종료값은 현재 트리의 사전값이 아니다(사이에 커밋이 있었다). PLAN-FORMAT runnable-DoD 규칙 "각 DoD 명령을 한 번 돌린다"를 문자 그대로 전부에.
  - **설계가 도구 행동에 기대면 그릴링 중 한 번 재현한다** — 리뷰가 "미검증"으로 공격한 지점을 8초 재현이 닫았고, 재현이 계약의 세부(Task ID vs Run ID)를 정정했다. PLAN-FORMAT 규칙 (d)의 재확인.
  - **zsh 글롭은 `2>/dev/null`로 못 막는다** — 셸 자체가 명령을 버린다. 비어 있을 수 있는 경로는 `find` 또는 `setopt nullglob`(CLAUDE.md 승급).
- 재확인(3회+ 반복 패턴): forge 메타 지시문 작업의 UAT는 grep DoD까지이고, 진짜 효과(4a 판정·벽 정지)는 실제 주행에서만 드러난다(회고 `260810-084115`와 같은 결론).
