# forge

Claude Code 플러그인 forge의 도메인 글로서리. 루프 스킬들이 공유하는 용어를 정의한다.

## Language

**eco 요약 표 (eco summary table)**:
`eco: true`일 때 작업 종료 지점의 산문 핸드오프를 대신 차지하는 화면 출력 형태 — 헤더 한 줄(제목·검증·divergence) + `▸ 요청` + `▸ 수행`(슬라이스 표) + `▸ 다음`. 산문에 덧붙이는 게 아니라 **교체**한다.
_Avoid_: 요약 — 기존 **봉인 요약**과 섞여 "요약을 내지 마라"(위임 경로)와 "요약을 표로 내라"(eco)가 같은 단어로 충돌한다, 간결 출력 — 압축(ECO.md `Terse communication`)과 구별이 안 된다

**봉인 요약 (seal summary)**:
명시적 단일 `/fg-done`에서만 렌더하는 마감 요약(요구사항·처리 내용·조건부 회고·메타). 위임·배치 봉인 경로는 이를 내지 않는다(ADR-0032). [[eco 요약 표]]와 별개의 것 — eco on이면 이 요약이 표 형태로 렌더된다.
_Avoid_: 완료 알림(completion notice) — 그건 봉인 요약이 대체하는 더 짧은 종전 출력이다
