# forge 모니터링

기존 forge 글로서리에 더하는 모니터링 용어.

## 용어

**모니터 세션 (monitor session)**:
한 프로젝트·브랜치에서 특정 Claude Code 세션의 작업과 에이전트 활동을 관찰하는 기간. 연결된 Claude 세션의 종료 또는 사용자의 모니터 종료로 끝난다.
_Avoid_: 프로젝트 전체 모니터 — 다른 브랜치나 다른 Claude 세션까지 자동으로 포함하지 않는다.

**모니터 기록 (monitor history)**:
모니터 세션에서 관측한 에이전트 상태와 최근 활동의 기록. 사용자가 보관 여부를 정하며, 기존 forge 계획·실행·완료 기록과는 별개다.
_Avoid_: 대화 전문 — 대화와 도구 입출력 전체를 저장하는 기능이 아니다.

**확인 불가 (unknown)**:
관측 근거가 없거나 끊겨 에이전트의 현재 상태를 판단할 수 없는 상태.
_Avoid_: 실패 — 실패가 확인된 상태와 다르다, 실행 중 — 오래된 실행 기록만으로 현재 생존을 단정하지 않는다.
