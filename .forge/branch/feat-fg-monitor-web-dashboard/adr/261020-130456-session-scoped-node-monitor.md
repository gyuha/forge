# fg-monitor는 Claude 세션에 연결된 읽기 전용 Node 웹 앱이다

사용자는 현재 프로젝트·현재 브랜치·현재 Claude Code 세션에 한정된 모니터를 선택했다. 여러 프로젝트를 통합하는 상시 서비스 대신 `/fg-monitor on`으로 시작하고 `/fg-monitor off` 또는 연결된 Claude 종료로 끝나는 구조를 사용한다. 작업 상태는 forge 파일에서, 에이전트 상태는 해당 세션에서 관측한 이벤트에서 읽는다. 둘을 혼동하지 않으며 관측이 불가능하면 ‘확인 불가’로 표시한다.

OS에 관계없이 Node로 실행해 달라는 요구에 따라 웹 서버·수집·수명주기 코어는 Node 단일 구현으로 둔다. ADR-0022의 일반적인 bash 본체 + Node 트윈 규약에 대한 **이 기능 한정 예외**다. 필요한 셸 진입점은 Node를 호출하는 얇은 래퍼로 두고 동일 명령의 결과를 검증한다. 기존 운영 스크립트를 전환하거나 루트 package.json에 `type: module`을 추가하지 않는다. 별도 프런트엔드 빌드가 없어도 배포 플러그인에서 바로 실행되도록 정적 자산과 Node 내장 기능을 우선한다.

기본 바인딩은 localhost다. 사용자가 `/fg-monitor on --host 0.0.0.0`을 명시한 경우에만 외부 인터페이스를 연다. 접속 키는 세션마다 생성하며 모든 데이터 경로에 적용한다. 프로젝트에서 첫 실행 시 모니터 기록의 삭제/보관을 묻고 `.forge/config.json`에 저장한다. 이후 변경은 기존 설정 진입점인 fg-config가 담당한다.

런타임 파일과 보관 기록은 최상위 `.forge/monitor/`에 자체 `.gitignore`로 격리한다. 브랜치 루트는 전체가 추적되므로 PID·접속 키·활동 기록을 그곳에 두지 않는다. 이 전역 저장 위치는 통합 관측 범위가 아니며, 프로젝트·시작 브랜치·Claude 세션 식별자로 접근 범위를 제한한다. 기존 forge 파일은 관찰만 하고 모니터 종료 시 지우지 않는다.
