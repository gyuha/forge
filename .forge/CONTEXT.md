# forge

Claude Code 플러그인 forge의 도메인 글로서리. 루프 스킬들이 공유하는 용어를 정의한다.

## Language

**Visual Companion**:
그릴링·대화 중 mockup·다이어그램·시각 비교를 브라우저 탭으로 보여주는 선택적 표시 채널이자, 사용자의 클릭·텍스트 입력을 이벤트로 받는 **보조 답변 채널**. 두 채널(브라우저·터미널)의 답은 병합해 읽고 모순될 때만 되묻는다. 단 대화를 재개시키는 것은 여전히 터미널 턴이다 — 브라우저는 워크플로우의 런타임 입력이 아니다.
_Avoid_: visual compose, 시각 브레인스토밍, 브라우저 모드, 표시 전용(입력도 받으므로)

**미봉인 잔여 (unsealed tail)**:
실행은 끝났는데 봉인되지 않아 루프가 닫히지 않은 작업. 활성 슬롯에 남은 `status: executed`가 이에 해당한다. **`executed/`의 park은 잔여가 아니라 의도된 대기**다 — 사람이 "나중에 회고하겠다"고 남긴 상태이므로, 잔여를 자동으로 닫는 경로는 park을 건드리지 않는다.
_Avoid_: 부채(debt) — 회계 은유가 "갚아야 할 의무"를 함의해 의도된 대기까지 싸잡는다, 미완 작업 — 백로그의 미실행 plan과 구별이 안 된다

**eco 요약 표 (eco summary table)**:
`eco: true`일 때 작업 종료 지점의 산문 핸드오프를 대신 차지하는 화면 출력 형태 — 헤더 한 줄(제목·검증·divergence) + `▸ 요청` + `▸ 수행`(슬라이스 표) + `▸ 다음`. 산문에 덧붙이는 게 아니라 **교체**한다.
_Avoid_: 요약 — 기존 **봉인 요약**과 섞여 "요약을 내지 마라"(위임 경로)와 "요약을 표로 내라"(eco)가 같은 단어로 충돌한다, 간결 출력 — 압축(ECO.md `Terse communication`)과 구별이 안 된다

**봉인 요약 (seal summary)**:
명시적 단일 `/fg-done`에서만 렌더하는 마감 요약(요구사항·처리 내용·조건부 회고·메타). 위임·배치 봉인 경로는 이를 내지 않는다(ADR-0032). [[eco 요약 표]]와 별개의 것 — eco on이면 이 요약이 표 형태로 렌더된다.
_Avoid_: 완료 알림(completion notice) — 그건 봉인 요약이 대체하는 더 짧은 종전 출력이다
